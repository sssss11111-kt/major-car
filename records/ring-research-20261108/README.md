## 适合本车的重构形态

1. 入口检测仍由视觉候选连续确认，单帧候选不能直接控制车辆。
2. 进入 `ENTER` 后只跟随本帧可验证的分支边界。目标点允许来自当前白色通道和标定宽度，不要求路径一定连到图像最远端。
3. 入口路径失败时使用有边界的当前帧走廊回退。回退必须逐点落在本帧白色区域，且限制相邻目标点横向变化，不能用固定舵机角度硬拐。
4. `ORBIT` 只由编码器累计运动推进，角度只开放出口判断。出口仍要求当前近场双边恢复连续确认。
5. 出环、冷却和视觉失效保护保持独立，不能用“看不到环岛”代替“已经出环”。

## 当前代码中确认的失效耦合

`img_process.c` 的 `ep_build()` 以图像中心为起点、以固定侧端点为目标，要求在当前二值图上找到一条完整路径。入口视野被车体遮挡、岛边贴近画面边缘或支路尚未延伸到固定端点时，搜索会返回失败。随后 `main.c` 没有入口路径就回到普通中线，只有很短的里程桥接窗口，容易在真实入口处失去转向。新候选保留原始路径搜索作为优先方案，并增加当前白色走廊的受限回退。
