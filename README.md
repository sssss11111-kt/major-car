## 当前N版命令

**启动后默认待机，不会自动运动。** 运动命令需人工确认场地；发送命令不等于实物一定按预期执行。`0`是ASCII数字零。

| 命令 | 行为 |
|---|---|
| `p / q / d / z` | 状态 / UART与方向诊断 / 行驶配置版本 / 舵机PWM寄存器；p也为10秒模式续期 |
| `s / S` | RX中断中立即零电机输出、回中、取消积压命令并确认故障；不等于主动刹车 |
| `1 / 2` | 左/右单轮开环30%、2秒，**架空测试** |
| `4 / 5 / 6` | 左/右/双轮速度闭环架空测试，目标80，4秒，最高30% |
| `c / l / j` | 回中1500 / 右1350 / 左1650，1秒后回中 |
| `7 / 8 / 9` | 独立落地直行/左转/右转，各驱动1秒，结束停车回中 |
| `0` | 独立落地直行10秒，需要持续p续期；采用脚本，不建议手工敲零后等待 |
| `w` | 静态视觉转向30秒，**两轮强制零**；需3帧有效图像，不是落地循迹 |
| `a` | 自动循迹启动，**尚未实车验收**；其PI、20%限幅与独立行驶测试不同 |
| `g / b` | 停车时获取灰度/二值帧；`o/t`切Otsu/固定阈值，`[/]`调固定阈值 |

状态模式：0待机、1循迹、2开环单轮、3故障、4速度台架、5静态视觉转向、6独立落地行驶。故障：0无、1摄像头、2图像超时、3丢线、4主循环超时、5编码器、6通信租约超时。

## 下一步优先级

1. 架空比较“左转后回中”和“右转后回中”各3次；检查摇臂螺丝、连杆、支架、前束、轮胎和轮轴，不通电强拧车轮。
2. 同参数同起点做重复测量，记录距离、偏移、最终朝向、地面方向和电池状态，再决定机械调整或软件微调。
3. 制作连续、平整、哑光的白底双黑边赛道；验证有效识别与左右误差符号，再做`w`静态视觉联动。
