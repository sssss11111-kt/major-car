## 恢复完整 ZIP

下载本分支（Code → Download ZIP）并解压，在仓库根目录运行 `powershell -ExecutionPolicy Bypass -File restore-archive.ps1`。脚本按顺序合并22块并校验SHA256，生成 `20261021上午例程测试.zip`（16,761,756字节）。由于连接器单次大文件传输失败，采用原ZIP二进制分块；没有删减归档内容。
