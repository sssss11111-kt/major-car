# 比赛交付目录

这里保存**准备上车比赛的稳定版本**及其可复现交付材料。学习过程、草稿和每周实验记录仍放在仓库的 `docs/`、`data/` 中；只有经过实际编译、烧录和赛道验证的内容，才标记为比赛可用。

## 交付结构

- `firmware/`：Keil 工程、实际使用的应用源码，以及构建说明
- `config/`：摄像头、图像算法和车辆联调参数
- `docs/`：硬件安装、算法说明、A/B/C 软件接口和操作步骤
- `evidence/`：实测照片、日志、视频和验收记录
- `release/`：每次候选版本的清单、版本号和已知问题

## 发布验收清单

- [ ] 记录 Git 提交号、版本号和发布日期
- [ ] 从干净工程成功编译，记录编译器 / SDK 版本和结果
- [ ] 已在目标 RT1064 硬件上烧录并验证
- [ ] 摄像头安装、曝光、ROI 与参数版本已记录
- [ ] 完成直道、弯道和实际比赛元素测试
- [ ] 记录连续运行时长、帧率 / 图像有效情况及失败样例
- [ ] 整车接口方向、单位、有效标志和异常处理已确认
- [ ] 保留可回退的稳定版本，并说明回退方法
- [ ] 清理个人信息、密钥、无关二进制和临时构建产物

## 当前状态

尚未发布正式比赛版本。目录中的 README 是交付模板；请在真实验证后更新清单，不要把待测状态标成通过。
