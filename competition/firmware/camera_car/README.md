# RT1064 C车模工程｜当前N版

更新2026-10-18。完整工程及逐飞V3.5.5/NXP库在本目录，当前源码包含无线修正、静态视觉转向、单/双轮架空速度闭环和不依赖视觉的定时落地行驶。

**先读[根README](../../../README.md)的当前命令表和[HANDOFF](../../../HANDOFF.md)。** 当前实测能力和限制不要沿用旧“5%/1秒单轮”说明。

## 工程入口

- `demo/mdk/rt1064.uvprojx`：真实摄像头工程，Flash 0x70000000，原DCD/SDRAM布局。
- `demo/mdk/rt1064-mock.uvprojx`：模拟图像、禁用电机，不能证明实体摄像头/运动。
- `demo/user/src/car_app.c`：外设适配、命令、遥测；`car_core.c`：图像/控制状态机；`car_servo.c`：舵机限幅。
- `demo/user/inc/car_config.h`：当前引脚和初值；[HARDWARE.md](HARDWARE.md)：已确认接线及边界。
- `tests/`：真实C核心与主机I/O替身、合成图像、串口/舵机/停止/超时测试，不替代实物。
- `tools/capture.py`：停车后采集灰度图；三种照明真实图集尚未完成。

## 当前命令和状态

运动命令：1/2单轮30%两秒；4/5/6左/右/双架空速度闭环80计数、4秒；7/8/9落地直/左/右1秒；0直行10秒（500ms没有p续期停车）；c/l/j中位/右/左；w静态视觉转向30秒两电机0；a循迹未实车验收。s/S中断停车回中，清旧命令。p/q/d/z只读状态/配置/寄存器，其中p也续期。

mode=0待机/1循迹/2开环/3故障/4架空闭环/5静态视觉/6独立落地。fault=0无/1相机/2图像超时/3丢线/4前台心跳/5编码器/6链路租约。

g/b停车灰度/二值图请求；o/t为Otsu/固定阈值；[/]调固定阈值；e/E待机调曝光；r停车重试相机。UART1/UART8均115200/8N1，UART8启动A5 FF FF握手，RTS低有效。图像协议00 FF 01 01后接188×120字节。

## 构建验证

本轮精确HEX由现有ArmClang6.7构建，原工程元数据6.21/Pack19；编译器/路径不同的重建不自动等同精确原件。仓库根目录的repair/build_arm.py按原工程源表/宏/链接布局构建；repair/run-tests.cmd使用本机MSVC路径，需按安装位置配置。原build.ps1/测试入口保留。

最新完整主机测试通过，数据在[新归档records](../../flash-tests/2026-10-17-to-18/records/ground-straight10-host-tests.log)。合成图像152场景与移动序列是软件验证，有已知反光/噪声局限，不宣称真实赛道准确率。

## 实物结论

C11左DIR/HIGH和C9右DIR/LOW均对应前进正计数；左右转1650/1350均回中；架空闭环与1秒落地动作通过；N版10秒直行多次完成，一次360cm/左偏5cm。机械回中重复性、轮距/轮径标定、标准赛道识别、静态视觉联动与a循迹尚待验收。

[23版固件/回读/数据](../../flash-tests/2026-10-17-to-18/README.md)明确区分历史版本。第三方来源与许可见PROVENANCE.md及libraries内许可证。
