# 比赛版本清单

每个候选或正式版本创建一份清单，例如 `v0.1.0.md`。版本信息必须来自实际发布，不要预先填写虚构版本号或测试结论。

## 版本清单模板

- 版本号：
- 发布日期：
- Git 提交号 / Tag：
- 目标硬件与摄像头：
- Keil / 编译器 / 库版本：
- 对应参数文件：
- 构建结果与构建人：
- 实机测试场景与结果：
- 连续运行时长：
- 已知问题：
- 回退到哪个稳定版本及步骤：
- 相关证据路径：
