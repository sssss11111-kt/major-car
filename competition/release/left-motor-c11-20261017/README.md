# 左轮 C11 方向控制已验证版本

2026-10-17：摄像头整合版，左轮连续两次架轮点动通过。每次左轮30% PWM、持续2秒后自动归零，用户确认向前转动并停下、右轮不动。左编码器两次分别为+186～+270、+185～+282计数/10ms，最终输出与计数归零、fault=0。

## 当前必须匹配的接线

| 通道 | PWM | DIR | 前进电平 | 编码器符号 |
|---|---|---|---|---|
| 左轮 | C6 | C11 → 驱动板LDIR | HIGH | -1 |
| 右轮 | C8 | C9 → 驱动板RDIR | LOW | +1 |

两板共地；黄色线当前接C11，不接原C7。右轮已在此前独立测试中确认前进正计数。本次固件保留该配置；未重复验收本次固件的右轮。

## 固件与命令

camera-car-left-c11-verified.hex 是实际烧录、读取校验并通过两次左轮实测的原始固件，SHA256：

`9c44808f9dedba25caec9daa73c79f015d010ab94d0557b937d02b42092ac027`

编译工具为ArmClang 6.7，主机回归为MSVC C11；原Keil工程的历史工具链设置另见工程README。

串口1测试左轮、2测试右轮，均30%、2秒，一次只驱动一侧；s立即置零并回中，p查状态，q查通信与方向诊断。上电不自动点动。测试为开环，保留前台心跳超时停车，不使用循迹模式的编码器堵转检测。

## 验证边界

C11静态HIGH=3.3V、LOW=0V已用万用表确认。引脚sample读回曾在实测HIGH时仍为0，因此不作为电平验收或拒绝点动的条件，也不能据此判断C7损坏。C7故障原因未确认。

尚未验收落地行驶、速度闭环、起转参数及循迹。循迹PWM上限仍为20%，不可从30%开环起转成功推断20%限幅的闭环能正常起步。
