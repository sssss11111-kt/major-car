# 右轮点动与方向校准已验证快照

右轮DIR=C9 LOW、编码器符号+1，串口命令2执行30% PWM、2秒后自动输出归零。用户确认右轮向车辆前进方向转动、随后停止，左轮不动；右编码器+271至+333计数/10ms。

左轮方向问题尚未解决，禁止据此直接落地循迹。此快照保留当时左轮HIGH、15%测试配置，不包含本地后续左轮30%及方向诊断改动。循迹PWM上限仍为20%，起转与闭环参数尚未校准。

- camera-car-right-verified.hex：当时已烧录、校验、实车确认右轮前进的原始固件。

- validation.json：验证范围与结果。

测试模式是单轮开环，保留串口s停止及前台心跳超时停车；不使用循迹模式编码器堵转检测。上电不会自动执行点动。
