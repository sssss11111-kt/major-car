## 控制边界

- `img_process.c/.h`：沿用灰度分带阈值，在黑条识别之后检测“两个白色通道夹一个宽暗岛”。要求暗区10..100px、两侧白段至少10px、连续8行边缘连贯、暗区宽度变化至少8px，且顶部有3行白色封口；排除矩形宽条、开放分叉和普通单通道弯。任意具有相同拓扑的阴影仍可能误识，需实拍验证。
- 连续3个有效新帧确认后入环；顺时针选岛左侧的当前实测白色通道，保持岛在车右侧。已确认环内时允许岛顶出视野后的当前双通道延续，绝不跨暗岛补线。冻结宽度学习，避免把环岛分支学成普通赛道宽度。近场至少6个实测有效行，否则停车；原误差每帧16px限幅与舵机平滑保留。
- `roundabout_control.h` 是唯一绕行状态与编码器累计角度的所有者。主循环逐帧观察，10ms监督中断累计左右轮差；等速直走、反向转动或重复图像均不能假装绕完。状态为等待→入环→环内→出口→防重入；到配置角度才恢复普通选线，随后4个干净近场帧确认离环，再等15个干净帧且前进0.30m后允许下一环。45s或10m未结束则故障8停车。
- `main.c` 只负责串接视觉/状态、原子发布、速度上限和遥测 `RING26 phase route island yaw10 fault`。环内上限80，普通直道100/弯道80不变；黑条24及退出缓升始终优先。条纹及其恢复期暂停环岛视觉检测/分支覆盖，不暂停真实编码器累计。原STOP、失线、超时、编码器和堵转保护均保留。
- 原转向控制与PID源文件、速度参数、69..116命令限位、中位92.5、PWM0..10000及508个SDK文件均保持。LAP25源码与已烧录HEX保留供回退。
