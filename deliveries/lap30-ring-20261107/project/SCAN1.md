# 新赛道扫描器整车工程

固件遥测标识为 `C11LAP30SCAN1`。Keil 工程入口为 `demo/mdk/rt1064.uvprojx`。请保留仓库目录结构，工程从 `firmware/camera_car/demo/user` 引用共享扫描器。控制、舵机、编码器、摄像头和 SDK 位于本工程。

## 识别与寻路

- 前台每个新摄像帧复用 R17 的分带阈值做轻量扫描。出现候选或 R17 正在进行环岛引导时做完整多区间扫描。串口状态行 `SP_SCAN` 包含类型、置信度相关诊断和入环放行状态。
- 扫描器参与接近及正式入环的放行。完整扫描失败、区间溢出、相互冲突、十字岛证据或反侧环岛证据都会阻止入环。截边导致拓扑不足时，由 R17-2 当前帧的环岛边界、入口进度、路径及 12 像素岛边余量共同决定是否入环。正式切换后的同帧路径仍要复核。
- 环内和出环继续执行 R17-2 路径及原停车保护。发现确认的十字岛时，若当前没有环岛引导，交给现有失线保护。十字岛自动寻路需要现场路线和车辆标定。

## 复核

在仓库根目录执行 `python deliveries/lap30-ring-20261107/tools/run-host-checks.py --current`。将环境变量 `ZIG` 指向 Zig 编译器。共享扫描器另有 `firmware/camera_car/tests/run_tests.py`。

主机回归覆盖灰度分带、普通循迹、起步、环岛、条纹、停车、十字岛无路线时的输出抑制及入环拒绝。历史手推回放 239 帧中有效 228 帧，和 R17-2 一致，两处正式入环仍在第 61、141 帧。该序列岛体常常截边，通用扫描器未单独确认环岛。Arm Compiler 6.21 命令行完成构建。板端时延及实车表现待验证。
