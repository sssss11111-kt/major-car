## 原因与修正

LAP26只检查连续双白通道、暗区宽度变化和局部三行白色封口；没有判断暗区是否从侧面/下方通向外部地板。开放的连续弯凹湾也可能通过这些条件。合成开口凹湾可在原LAP26稳定复现误触发；这证明代码缺口，不等于取得了现场误触发帧。

LAP27在原几何初筛通过后，才对18..105行区域进行外部暗背景8邻域连通搜索，从四侧边界标记可达暗像素。候选中心暗区只要与外部相通，就不能作为入环证据，斜向一像素缺口也按开放处理。还要求至少12个连续封闭行、累计暗面积至少180px，然后仍经过原三帧确认。暗区需在当前视野内完整封闭；视野不完整时宁可推迟入环，不能当作已经可靠识别。已确认环内的当前分支延续逻辑不变。

实现仅修改视觉所有者img_process.c，main仅更新固件/遥测版本。轮距0.155m、图1→图2顺时针的路线假设、270/360门控、速度100/80/80/24、69..116限位、转向平滑、PID与全部停车保护不变。黑条先处理，条纹及恢复期间仍不进入环岛检测。LAP26原源码与HEX保留。

连通搜索无递归、无堆分配、不改原图；固定bitset+队列共35,968字节，每像素最多入队一次，只有原几何候选出现才执行。构建ZI149,760字节。板上最坏处理时延仍需通过原时延遥测检查，不能由主机耗时推断。
