## 修改

保留完整岛四侧封闭检测，补充侧向裁切岛：8邻域组件只能接一侧图像边缘，与ROI上下界均留至少3行；高至少24、宽24..110、面积至少400、填充至少1/3，贴侧至少6行，上下三行端部均比最大宽窄至少12像素，并要求几乎每行均有至少10像素当前白色通道。矩形、贯穿上下的外部地板、细对角连接、普通波浪测试仍被拒绝。沿用三帧确认、当前近区有效条件、黑条优先及恢复屏蔽。这是针对当前相机的初值，不能声称任意弯道/阴影都不会误判。

侧向分支按可见方向标记，不使用被画幅裁掉的分支。环岛控制统计只计当前白色中心点。入环ENTER阶段、当前已选择的分支预瞄至少10行有效时，才将近误差向分支方向辅助35%，最多12像素；仍由原三帧中值、时间滤波、变化率和69..116限位控制。未确认、无分支、条纹、失线及非ENTER阶段均不使用这项辅助，禁止固定盲打角。

原转向所有者、PID、速度100/80/环80/黑条24及停车锁定不变。轮距暂15.5cm；两环顺时针、先图1后图2、270/360度门控仍是待确认配置。跳过第一环仍会使后续route索引偏移；本版不声称能从单张局部视野自动区分两环。须从完整配置路线验证。

连通分析复用35,968字节静态工作区，无递归和堆。侧向检查在完整岛未成立时运行，最坏可能多一次全ROI遍历；没有板上新时延数据，需观察TIME28，不能用主机时长代替。
