# LAP21 连续弯道转向与提速

LAP20已由用户确认能走完全程，但过弯前轮抽搐，存在多次幅度过大的转向。LAP21是本次编译的候选，尚未烧录或实车验证；LAP20源码和实际烧录HEX完整保留。

## 修改依据

LAP20在近误差达到6px、预瞄达到10px或远近差达到6px等门槛处，将增益0.50直接切为1.00，并启用另一条打角曲线。门槛附近波动会放大命令跳变；远处预瞄也没有独立的连续帧滤波。这些是代码中已确认的机制，但目前没有同步轮角录像或连续原始弯道图，不能认定它们已解释全部机械抽搐。

## 本版策略

- 用近偏差、远处预瞄、远近差构造0～1的相对弯曲程度，平滑插值0.50～1.00增益及线性/参考曲率打角。缓弯小打角、急弯更充分打角；不再用一个开关把两套输出生硬切换。
- 近误差6～30px、预瞄10～40px、远近差6～32px为经验归一化区间，不是物理弯道半径标定。转弯标签0/1/2/3仅作诊断，边界带0.03滞回；控制量保持连续。
- 三帧中值拒绝孤立跳点，再按实际10ms计数间隔做一阶滤波。近处通常时间常数40ms、明显大偏差时20ms；预瞄40ms。预瞄需连续两帧有效，失效即停用，不把旧预瞄继续当观测。
- 舵机指令变化率随弯曲程度由110到220命令点/秒，左右对称，持续急弯仍能到124/61；S弯换向连续经过中位，不增加固定等待。按实际帧间隔计算，单帧最多计40ms，时间计数回绕、重复计数均有检查。这是软件命令速率，不是前轮机械角速度。
- 弯前可据预瞄降低目标速度，回正后速度比例每秒最多恢复0.8；轮子仍有大转向命令时保持降速，减少一边回正一边突然加速。
- 直道目标45→67.5，满打角急弯24→36，单边目标上限24→36，均为counts/10ms。PID 50/0/0、前馈1500、完整0～100%PWM范围保留。实际速度提升不能仅凭目标值宣称。
- 维持中位92.5、限位124/61、50Hz；保留可靠赛道识别→回中1秒→自动起步，以及失线、帧超时、编码器异常、堵转、STOP锁定至复位。
- 新遥测标识C11LAP21、TIME21、STEER21；新增bend、sev1000、slew。geom_cal仍为0，不把估计打角说成按厘米闭环控制转弯半径。

## 已验证与边界

Keil ARM Compiler 6.7：0错误0警告；实际HEX含LAP21标识、不含LAP20标识，69,056有效字节。主机序列检查覆盖连续门槛、左右镜像、孤立跳点、限速、持续急弯及反向急弯全行程、回正加速、预瞄失效、无效帧复位、重复tick和计数回绕。实际trial_tick/PID的8个监督用例和两张真实直道各60帧回放通过。

转向模块主机编译使用/W4 /WX通过；监督/图像桩编译中保留了既有整数到float转换及源文件代码页警告，不能把主机全过程描述为零警告。MCU构建为零警告。

没有连续弯道原始帧和轮角真值，因此未证明实际抖动消失、每种弯道半径、50%实速提升或提高速度后的整圈可靠性。滤波与变化率限制会增加一部分指令响应时间；本版以持续急弯可达全行程作软件约束，真实高速过弯仍须验证。后续先对照LAP20同一赛道测试，不根据故障码直接取消保护。
