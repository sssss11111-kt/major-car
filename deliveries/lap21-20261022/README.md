用户确认障碍是平面黑色条纹区域。处理流程：正常循迹 → 多行条纹识别 → 按当前外侧边界计算中线、降级通过 → 连续3帧无条纹后恢复普通循迹与预瞄。没有跳坡、冲坡、定时盲行或通过后停车动作。

- 在原始灰度图的18..105行、白色连通段提取前识别条纹；至少4条黑条，条宽2..18像素、白间隔2..26像素、总跨度至少40像素，宽度/间隔比例不超过3倍；至少4个相邻行的条纹中心相差不超过6像素。
- 条纹行只使用当前可见的左右外侧边界，中线可以落在黑条上；外侧宽度须符合原透视模型±15像素。边界不可见或宽度不可信时舍弃该行，不以历史中线授权继续行驶。
- 条纹帧冻结赛道宽度学习、关闭远处预瞄，且至少有6个近区(80..105行)当前观测行。远区干净但近区失效时判失线，沿用fault4停车。
- 条纹及恢复期按降级模式处理，速度目标上限24 counts/10ms；正常直道45、急弯最低24、PWM可用范围0..10000、舵机92.5/124/61与转向增益保持。实际输出仍由PID决定。
- 条纹不能用于自动起步；正常可靠赛道识别→回中1秒→自动起步不变。STOP、200ms图像超时、失线、编码器异常、堵转与停车锁定均保持。
- 新增遥测 `STRIPE21 active=... rows=...`；`rows`为本帧条纹候选行，`active`包含退出恢复期。条纹重建不计作真实双边标定行。
