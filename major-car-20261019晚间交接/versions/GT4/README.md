# GT4右缓弯：目标40、10秒动力阶段

用户最新指令优先：先右缓弯，延长10秒，并希望提速。相对GT3仅将目标30→40计数/10ms，动力5000→10000ms（准备仍200ms），版本身份更新。输出上限保持30%，未进一步扩大功率；GT3实际PI输出约12%～14%，提速通过增加闭环目标实现，不能把30%上限说成恒定30%输出。

沿用GL2地面PI、误差减速（实际目标20～40）、Kp4、Ki20/秒、积分±500、前馈896+[15.5,15.1]*目标、零输出下限、30%200～300ms起转、200ms后PI接管。目标40的前馈1516/1500为外推，未进行地面全速度稳态标定。

视觉算法、舵机中位/增益、待机无效30帧后重捕获不变。保留150ms图像时效、3帧无效、100ms前台、500ms通信租约、反馈-5/120、连续500ms低反馈及RX s急停。设备保护可提前中止，不能为跑满10秒放宽保护。普通缓弯短段测试，不宣称环岛/十字或整圈通过。

实际C适配器与主机回归、GT4工具9项检查通过。构建命令使用CAR_TRACK_GROUND=1、CAR_TRACK_FAST=1。精确HEX、SHA、烧录/读回、冷启动与实体轨迹分层记录。
