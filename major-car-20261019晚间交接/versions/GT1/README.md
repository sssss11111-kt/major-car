# GT1地面视觉循迹候选：3秒动力阶段

用户接受GL2两次落地结果作为下一阶段依据，不再测第三轮；保留首轮速度未达标和第二轮达标，两次实物均正常行驶、自动停止。未声称连续三次通过。

GT1将GL2地面PI提取为共享ground_pi_step，并用于视觉循迹；GL2独立固定目标20保持相同公式。Kp4、Ki20/秒、积分±500，初次积分抵消P项；前馈左896+15.5*目标、右896+15.1*目标，目标20时分别1206/1198，与GL2一致。闭环输出0～15%，无最低PWM硬限/自动再起转，30%起转200～300ms后立即PI接管。

视觉算法与转向增益、中位不改；保留视觉误差使目标在10～20计数/10ms变化的规则。不同动态目标尚未全部实车标定，仅用于直道短试，不宣称弯道能力。

用户要求延长观察，本候选200ms零电机准备+最多3000ms动力，总约3200ms。启动需3帧新鲜有效图像；150ms图像时效、连续3帧无效、100ms前台、500ms显式通信租约、反向-5与120计数/10ms反馈上限、500ms低反馈和RX s急停均保留。120比G1的450更严格。

Keil原工程默认宏仍为历史G1；本地build_arm.py明确使用CAR_TRACK_GROUND=1、CAR_GROUND_DIAGNOSTIC=0、CAR_GROUND_CLOSED_DIAGNOSTIC=0，精确GT1 HEX和构建命令在本目录保存。不拿历史G1工具代替GT1参数核验。

tracking_gt1.py默认仅d/p预检；--run只发一次a、持续p续期，正常结束后s及独立停车查询。每次运动先确认复位摆位，无自动重试。正常结束和实体沿线行驶分别判定。
