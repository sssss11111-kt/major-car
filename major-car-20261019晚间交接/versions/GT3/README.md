# GT3直道纠偏：30%输出上限、5秒动力

用户明确要求继续直道纠偏，并允许占空比提高至30%、增加运行时长。本候选闭环目标从20改为30计数/10ms，输出上限由15%提高为30%，动力3000ms改5000ms，准备仍200ms。实际占空比由PI控制，不强制持续30%；无速度单位换算，不保证车速提高比例。

GT2视觉算法、舵机中位及转向增益、误差减速规则、待机历史重新捕获保留。沿用Kp4、Ki20/秒、积分±500，前馈896+[15.5,15.1]*目标、PI首步抵消P项。目标30的前馈为1361/1349，是基于10%/20%地面两点模型的外推，尚未做地面稳态标定。闭环30%上限仅用于本次循迹模式；GL2独立低速测试仍15%上限，历史默认配置0也保留15%。

保护保留：3帧新鲜有效图像启动、150ms图像超时、连续3帧无效停车、100ms前台、500ms通信租约、-5/120计数/10ms反馈异常、持续500ms低反馈、RX s急停。启动30%200～300ms；总运行约5200ms，提前故障终止不算正常到时。不放宽编码器保护。

构建脚本使用CAR_TRACK_GROUND=1、CAR_TRACK_FAST=1；Keil默认宏不等于此候选。精确HEX和构建命令另存。tracking_gt3.py严格核验GT3、目标30、5秒、30%闭环上限，默认只查询，--run只发一次a，无自动重试。

软件与硬件证据分开记录。烧录前完整备份同板Flash并核验GT2，烧录读回后仍须用户确认冷启动、复位摆位和前方空间。直道实测需用户报告是否朝中线纠偏、前进/侧偏、碰线/出界、自动停稳，不能把遥测正常当作整圈验收。
