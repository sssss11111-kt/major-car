## GT4D变化

控制源码、速度目标40、输出上限30%、动力10秒、舵机/视觉参数及全部保护不变。仅更新版本身份与诊断：

- 收到s时若原模式为运行或故障，先在内存保留时间、试跑ID、原mode/fault、原PWM、通信租约/前台心跳年龄、无线RX/error/drop和RTS；重复s不覆盖有意义记录，下一次a清除记录。
- Z查询DIAG-STOP，不驱动车辆；记录不写Flash，重启会丢失，需结合启动信息/设备ms判断。
- 记录前台观察到的RTS连续高电平最大时长；不是示波器全时波形，前台卡顿期间覆盖有限。
- 主机tracking_gt4d.py保存每次写/读开始与完成时间、读长度、缓冲字节和原始串口偏移、完整状态到达时刻、停止尝试及残余半行，保护超时不变。
