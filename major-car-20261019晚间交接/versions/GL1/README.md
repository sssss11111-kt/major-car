# GL1地面低速闭环候选

用户在20%固定输出测量后要求继续同速闭环与起转到PI过渡测试。保留G1/GH1/GH2源码、固件和所有测试数据。

## 参数依据与变化

GH1地面10%最后500ms均值左6.70/右6.90；GH2地面20%左71.24/右73.20。对这两档数据作直线插值，目标20的估计输出分别约1206/1198。这是初始猜测，非已验证的完整负载模型；未测电池电流、电机端电压、RPM或单位距离。

GL1独立诊断模式固定舵机1500us、双轮目标20计数/10ms，不接入视觉纠偏。准备200ms；30%起转200～300ms，两侧各连续三次>=5确认。随后立即进入PI，不再等至电机阶段1000ms。初次PI以15%闭环上限为输出种子并限制积分；Kp4、Ki20/秒、积分±500，后续随反馈调整，输出限幅0～15%，无显式最低PWM硬限或自动再起转。30%起转退出时受到15%闭环限幅，不能称为整个30%到PI输出无跳变。

独立控制共1500ms，整体最多2000ms。反向-5、反馈上限120计数/10ms、500ms持续低反馈、100ms前台、500ms通信租约及RX s急停均保留。a循迹仍拒绝。GL1仅在本地构建脚本设置CAR_GROUND_DIAGNOSTIC=1、CAR_GROUND_CLOSED_DIAGNOSTIC=1时启用；精确HEX见firmware。

## 测量与验收

最后500ms各50点，保存均值、RMSE、最小/最大。候选判据：均值距20<=2、RMSE<=5、最小>=2、最大<=40、双轮均值差<=2；正常到时、故障、性能达标、实物运动分别记录。短时通过不代表长期全电量稳定。

W只查询与续期；Y单次启动；主机默认不发车，--run明确单次开始。每次烧录和运动分别取得现场确认，无自动重试。源代码原L3/视觉参数未改，本版只验证独立地面闭环。
