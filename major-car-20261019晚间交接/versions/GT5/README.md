# GT5 本地按键循迹测试

基于GT4D，默认使用C15（逐飞KEY_1，按下低电平，上拉输入）。C12/C13/C14为库中其他按键，现选当前工程未占用的C15。引脚集中定义在car_app.c的CAR_TEST_BUTTON。改变引脚须重新编译并检查占用。

## 操作

1. 冷启动后先松开按钮。摆正车辆，确认相机清楚看到赛道双边、前方清空，可随时切电。
2. 按一下C15并松开，屏幕显示KEY1 WAIT 2s。2秒后重新检查识线、新鲜图像、主循环、静止编码器和零电机输出，全部满足才启动；不满足则拒绝，绝不自动重试。准备转向200ms，动力最多10秒。
3. 等待或运行中再按一次C15可取消/停止；松开不会自动重新运行。上电按住、一直长按和短抖动均不会自动启动。
4. 屏幕M为模式、F为故障、V为当前识线有效性；M0为空闲，M1为循迹，M3为故障。故障后按一次清除并保持停止，排查后再重新按一下申请测试。
5. 串口s仍立即停车。按键停止需主循环采样并经过30ms去抖，不是硬件急停；异常时直接切电。

## 运行边界

速度目标仍40计数/10ms（视觉降速20～40），PWM上限30%，起转参数及PI与GT4D一致。识线连续3帧无效、图像150ms、主循环100ms、编码器异常与10秒时限保护保留。car_core.c不改。

按键启动在健康主循环中维护本地租约，不要求无线p命令；主循环卡死仍由100ms保护停车。串口a启动仍要求原500ms无线租约。运行结束、故障或停止后取消本地续租。由按键启动时无线掉线不会单独导致停车，因此需现场看护；它支持脱离电脑运行。

源码启动信息、TRACK-CFG、DIAG-STOP标识为GT5；旧GT4/GT4D专用启动工具会因版本不符拒绝，勿改其校验强行使用。只读采图工具仍可使用。

本版只新增操作入口，不修复模糊画面或识线算法，也不代表右弯已验收。需先验证按键功能、识线和自动停止，再做右缓弯。

## 验证与烧录

详见validation.json及records中的构建/回归证据。主机测试包括真实car_app/car_core适配器的去抖、上电按住、倒计时取消、无效识线/非零编码器拒绝、本地无无线续租10秒到期、按键停止、串口停止、丢线、主循环看门狗和远程租约。

烧录前必须确认电池关闭、DAP连接正确、核心板灯亮且驱动轮架空。烧录完成不启动运动；断开DAP并冷启动后由现场人员按键测试。
