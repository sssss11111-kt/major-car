# BDS300 舵机初始化与回中

## 查找结果

原程序已有初始化：car_app_init() 中先 pwm_init(CAR_SERVO_PWM, CAR_SERVO_HZ, 0)，再输出中位脉宽。本次将它提取为 car_servo.c/.h 独立模块；应用以中位占空比调用逐飞 pwm_init，PWM 换算与限幅统一在此模块维护。底层定时器启动和占空比装载时序由 SDK 完成，具体波形仍需实测。

## 入口与调用顺序

- 实现：demo/user/src/car_servo.c。
- 声明：demo/user/inc/car_servo.h。
- 参数：demo/user/inc/car_config.h。
- 应用入口：car_app_init()，在开启 PIT 定时控制之前调用 car_servo_init()。
- 硬件输出尚未准备好时，串口接收不会访问未初始化的 PWM，也不会缓存运动命令。

```c
#include "car_servo.h"

/* 完成系统时钟初始化后、启动控制定时器前调用。 */
car_servo_init();           /* C30，50 Hz，1500 us 中位 */
car_servo_set_us(1600.0f);  /* 限幅到配置范围后输出 */
car_servo_center();         /* 回到配置的中位 */
float command_us = car_servo_get_us();
```

上述 setter/center 仅在初始化后调用；init 用于启动阶段，不能在定时控制运行中随意重新配置 PWM。示例的三个动作是 API 用法演示，不是自动执行的开机扫舵流程；正式程序上电只回中，不自动左右扫舵。

## 默认参数与换算

| 项目 | 当前值 |
|---|---|
| 舵机 | BDS300 |
| PWM 引脚 | PWM4_MODULE2_CHA_C30 |
| 频率 | 50 Hz，周期 20,000 us |
| 中位命令 | 1500 us |
| 起始允许范围 | 1350～1650 us |
| 逐飞 PWM 标度 | 0～10000 |
| 中位占空比 | 1500 / 20000 × 10000 = 750，即 7.5% |
| 两端占空比 | 675、825 |

参数是起始配置，不是实车测得的 BDS300 机械中位和限位。实际前轮中位、连杆方向和机械范围仍需校准。修改配置后重新编译；数值超出范围时夹紧到边界，NaN/正负无穷回中。getter 返回最近一次限幅后的命令脉宽，不是舵机角度反馈或测量值；50 Hz、10000 标度下 PWM 脉宽分辨率约 2 us。

## 不开车的检查方法

架起或断开驱动轮动力后烧录。上电应保持中位；串口 c 为中位，l/j 为小/大脉宽端，端点测试 1 秒后回中。s 随时停止电机并使舵机回中。l/j 只代表脉宽两端，物理左右方向尚需实测。屏幕或摄像头失败时不需要重写舵机初始化代码；摄像头故障可先发 s 确认，处于待机后进行舵机命令测试。

## 软件验证

新增独立舵机测试，检查 C30/50 Hz/中位初始化请求、限幅、回中、非有限数值处理、重复初始化；应用测试还检查初始化前 RX 不写未初始化 PWM。既有停车与图像测试一并运行。主机测试使用 I/O 替身，不证明实物脉宽、供电或机械位置已正确。
