# GT6 灰度画面与彩色识别标记

用途：逐飞1.8寸SPI、128×160 TFT屏，相机对焦及识线调试。该规格与现有tft180驱动一致，保留驱动初始化及其引脚，实际屏幕控制器和接线兼容性仍需现场验证；商品截图不能证明具体接线。

## 显示

- 上部128×82：原始188×120灰度图按比例缩放，未先二值化。
- 蓝点：检测到的左边界；绿点：检测到的右边界；红点：算法中线（单边推算时也可能出现）。标记不代表整帧识线通过，须结合V和PAIR。
- y=84：M模式、F故障码、V识线有效性。
- y=100：PAIR有效双边行数/扫描行数、T二值化阈值（用于算法，灰度底图不受其二值化）。
- y=116：CAM FAIL:CHECK表示相机初始化失败；CAM NO FRAME表示尚无图像或帧超时；正常时显示E图像误差、F帧计数（此行F是帧数，不同于第一行故障码）。
- y=132：C15等待/运行/启动提示。所有文字使用8×16字体，保留到160像素底边的余量。

图像标记为原检测点，不凭空连接缺失边界。传回电脑的g仍是原始灰度，b仍是二值图，屏幕彩色标记不写入采集缓存。

## 屏幕连接

沿用库的SPI3：SCL/SCK=B0，SDA/MOSI=B1，RES=B2，CS=B3，DC=C19，BL=C18，SPI 40MHz。电源电压以实际模块丝印/说明书为准。断电接线，不根据商品照片猜电源引脚。

## 运行与调试

基于GT5独立保存，car_core.c和C15逻辑保持一致：C15按下松开，等待2秒后重新预检，动力最多10秒；再次按下停车。调相机期间不要按C15。识线、图像超时、主循环、编码器、租约保护不改，速度目标40计数/10ms、PWM上限30%不改。版本标识20261019GT6。

先断电换接屏幕并检查排线，烧录后断开DAP、冷启动，仅看画面和只读采图。若CAM FAIL，先排查摄像头供电/排线/转接板，不把它当作对焦问题。正常出图后再小幅调整镜头对焦；不以短暂V=1替代稳定识线检验。

烧录前需要电池关闭、DAP正确连接、核心板灯亮、驱动轮架空。固件编译和主机测试不代表新屏实物显示、相机初始化或赛道验收通过。
