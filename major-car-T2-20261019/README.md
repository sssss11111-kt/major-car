# T2 左轮联动增驱架空测试版

版本 `20261019T2`。基于 GitHub T1 提交 `4994cd55933269ad1c948f3f5ff87e8fa47b28f3` 的577文件已核验源码，单独复制后修改，原T1保留。

本版用于验证左轮低占空比驱动不足的假设，仅安排驱动轮离地的短时测试。固定30%左轮测试时有明显反馈；原联动闭环降至约15%~17%后左轮未持续转动，用户观察左轮未动、右轮正常。机械卡滞及其他硬件因素尚未排除。

左轮循迹闭环PWM基准由1500提高到2200（15%→22%）；右轮保持1500。实际PWM=基准+比例项+积分项，再限制在0~3000，22%不是强制下限。起转30%、速度目标20、PI增益、200ms准备、3秒运行、500ms通信租约、图像/前台/编码器保护均保留。单轮字符1、独立测速和7/8/9驱动测试保持原基准。

`code/` 为完整源码；`firmware/` 保存编译后固件；`records/` 保存差异、哈希和软件验证日志。修改步骤见修改记录.md。

本机验证不能证明机械问题已解决。烧录和实车测试须另留现场记录；测试前对准赛道并确保真实图像ready，未ready不启动。不用于提速或直接地面循迹验收。
