# L1 低速闭环标定候选

第二目标进行中：根据H1架空维持测试，引入左右独立前馈和PI，在独立CAR_LOW_SPEED模式9中验证，随后再依据实物结果决定循迹控制参数。当前原循迹、旧速度测试、H1维持测试行为保留。L1尚未烧录或实物测试，不把主机固定反馈测试称为真实控速验证。

基线：车上H1，左6%三次持续、5%三次停转；右8%三次持续，7%两次持续一次停转，6%三次停转。这是起转后3秒架空结果，并非静止起转、长期或负载限值。

L1候选：目标默认20计数/10ms，待机时以5为步长调整10至40。左前馈为430+6.5×目标，右为560+7×目标，均为PWM满量程10000的原始单位；为H1数据附近的初始估计，待实物校准。PI为Kp4、Ki20/秒，10ms更新，积分±500、带饱和抑制，不设最低占空比硬限，允许超速时降至0。起转PWM30%，至少30ms并连续3点反馈≥5即独立转入闭环，200ms未确认则停车；闭环上限15%。左右轮独立起转确认，无失速自动重启。

命令Q查询及续租，F/G待机调目标，J左、N右、B双轮。每次6秒自动结束，最后3秒逐10ms统计300点的反馈和、最小/最大、绝对误差和、平方误差和。每次试验独立ID，明确done只由正常到时置位；s及故障清除done。手动s在RX中断立即零输出并取消排队动作。

保护：500ms显式查询租约、100ms前台心跳、反向小于-5、正向大于450计数/10ms、未选轮绝对反馈大于10、起转失败、闭环连续500ms反馈低于2，均停止。不增加编码器倍率，不放宽原普通模式保护；不含电流和温度检测。图像传输及相机重初始化不能在新运动模式中启动。

`code/repair/test_low.ps1`默认只预检，显式`-Run`启动恰好一次动作；Motor1左、2右、3双轮。启动前确认硬件身份、版本、参数、零输出和零反馈；验证新ID、起转确认、完整采样窗口、到时停止和最终新鲜零状态。H1曾缺失单条配置回复，因此仅允许待机查询最多3次，不重试运动。通信异常、保护或身份错误中止；`needs_tuning`表示有效测量但性能未达标。

候选验收：20目标下，各轮最后3秒均值误差≤2计数/10ms、RMSE≤5，最低反馈≥2、最高≤40。先单轮再双轮；双轮还检查均值差≤2，并重复至少3次。另用30目标交叉检查。未满足时基于实测调参，不将一次通过当成完成。当前只推进第二目标，不落地测试。
