## 可复现范围

`code/competition/firmware/camera_car`是当前G1完整逐飞V3.5.5/NXP工程，包含原许可证。`code/repair`为当前主机工具。每个C2～G1版本另保存用户源码、Keil工程、测试、主机脚本的覆盖快照（`versions/<版>/source`），搭配同一SDK可还原对应源码；C1只保留实际生成HEX，未取得其独立完整源码及烧录证据，不补造。

每版包含实际HEX、最终验证状态、原始串口字节、状态/结果、构建及主机测试日志。`serial.bin`逐字节保留，空文件也保留以证明当时无通信。公开文本将本机工作区路径改为归档相对路径；[provenance.json](provenance.json)同时保存本地原始与公开文件SHA，便于区分路径归一化和原始证据。完整4MiB私人Flash备份、下载器唯一ID、依赖环境和编译对象不上传。

主机回归与ARM编译在原现场目录通过；归档后另进行主机回归及完整性核验，结果见`publication-validation.json`。编译器为现场ArmClang6.7，MSVC C11用于主机测试；Keil工程元数据6.21不表示换编译器可得到相同字节。**精确已烧录字节以本归档HEX及其回读记录为准。**
