# 特殊赛道扫描与离线验收

本次以 `1109环岛` 的 `6d4ccb63ebecc1a189565b76a2830e7f5fba82e6` 为基线，修改 `firmware/camera_car`。分支中的 R17 实车交付工程位于 `deliveries/lap30-ring-20261107/project`，有独立的构建和入环修正。

## 采样和分类

`car_app_foreground()` 在每个新图像帧调用原 `vision_process()`。扫描器复用极性归一化后的二值图，路面像素统一为 255，因而同时支持 `white_road` 开关。原视觉结果继续直接传给 `control_frame()`。

| 参数 | 默认值 |
| --- | --- |
| 采样区域 | 第 40–106 行，避开 R17 记录的车体遮挡区域 |
| 轻量 / 完整采样 | 6 / 12 行，均匀采样 |
| 最小区间 / 通道 / 暗间隔 | 6 / 16 / 8 像素 |
| 每行容量 | 4 个有效区间，遇到第 5 个即标记整次扫描溢出 |
| 相邻行关联 | 暗区和两侧通道重叠，暗区端点位移不超过 18 像素 |
| 候选开启 / 解除 | ≥30 / ≤14 分 |
| 置信度下限 / 投票 | 70 分 / 最近 5 帧至少 3 帧一致 |
| 候选待确认 / 环岛接近证据 | 300 / 650 ms |
| 失证 / 活动上限 / 冷却 | 180 / 8000 / 400 ms |
| 恢复 | 连续 3 帧有可信普通道路 |

分数由多区间行（最高 35）、连续暗区（25）、同向曲率（36）、边界跳变或截边（30）及普通双边丢失（16）相加，上限 100。曲率使用相邻扫描行的边界方向变化。图像截边可启动完整扫描，截边部分的拓扑记为证据不足。完整扫描在候选和诊断活动期间逐帧执行。每个区间保存两端、中心及宽度。当前默认值由合成图和已有图像回放检查，仍需现场标定。

- 十字岛要求居中的连续暗区、至少 4 个关联扫描行，以及近端分叉、远端汇合。
- 环岛要求至少 5 个关联扫描行、同侧暗区、通道两边至少 2 个连续同向转折、近端通道汇合及近期的普通道路观察。投票同时匹配岛体所在侧。图像左右侧仅用于特征关联。
- 低对比、溢出、竞争拓扑或证据薄弱会保留 `SPECIAL_UNKNOWN`。当前帧必须有对应证据才能确认。活动类型在恢复或超时前保持锁定，短暂丢证时对外报告 UNKNOWN。超时是扫描诊断状态，原控制器继续执行既有停车策略。

## 路线接口

- 十字岛阶段依次为接近、入口对齐、绕岛、指定出口捕获、恢复。
- 环岛阶段依次为接近、入环、环内、出口搜索、指定出口捕获、恢复。正式入环要求入口、方向、对齐、当前路径、接近进度和内侧余量连续满足条件。出口搜索还需要环内进度，出口捕获需要匹配配置端口。关键观测超时进入各自的 FAILSAFE。
- 路径接口按入口、跟踪、出口分段，坐标为相机图像像素，点按近到远排列。入口工具检查普通中线接续偏差、整段每行对当前内侧边界的净距、最大离散曲率。边界缺失时拒绝；单边中线工具要求提供已标定宽度。像素净距和曲率用于图像诊断，地面净距和转弯半径需独立标定。
- 固件接入仅启用诊断。路线默认禁用，`route_ready=0`、`target_valid=0`。A–D 端口和方向由后续现场配置提供。原舵机 PD、双电机 PI、10 ms PIT、串口急停和故障策略保持原有行为。

串口在状态变化时排队输出 `SP_TRANSITION`，约每 500 ms 另有简短状态。字段采用枚举编号，定义见 `special_track.h`、`cross_island.h` 和 `roundabout.h`。队列沿用原先的有界非阻塞发送。

## 复现

在 `firmware/camera_car` 下运行：

```powershell
python -m pip install --target .tools ziglang==0.16.0
python tests/run_tests.py
```

主机测试编译实际 C 源文件，使用 `-std=c99 -Wall -Wextra -Werror`。输出 `tests/out/special/report.html`、逐例 TSV、灰度和二值 PGM、扫描叠加 PPM。旧的视觉、控制、应用急停和采图测试继续由同一入口运行。

历史 `manual-02` 手推采样的回放沿用 1–85、111–264 帧，段间复位。原始图像的 SHA-256 与 CRC32 逐帧复核。该序列的局部岛体频繁截边，扫描器可以触发诊断，但未确认环岛。实拍完整入口、环内、指定出口、相机到地面标定和舵机到轮角标定仍需补齐。板上处理时延和闭环行驶均待测。
