# 红砖回放数据

使用《红砖问题对照-2026-11-06 (1)(1).html》回放页第 100–200 张，首尾均含。原文件的回放编号、车端帧号、PGM 路径和 SHA-256 见 `manifest.json`。附件总计 221 帧。提取时逐帧校验灰度 SHA-256、原记录 CRC32 和冻结分析结果的同帧 SHA-256。

`frames-100-200.bin.gz` 保存 188×120、行优先、原始朝向的单通道 8-bit 灰度像素，以及每帧 120 个 SF2 分行阈值和 360 字节的显示边线。二值图按 HTML 的 `gray > threshold[y]` 原样重建为 0/255。二值图是同一原图的 **SF2 离线回放结果**。显示边线含补线与历史估计，不能直接作为实测边界。采集时电机关闭，由人工摆放红砖或推动车辆。

`labels.json` 记录从原图人工目视标出的红砖可辨认正面、明确无砖帧和排除项。亮顶面和模糊阴影未纳入正面框。正面框仍待独立复核。同次连续采集的画面高度相关。未列出的帧默认未标注。

```powershell
python data/obstacle/extract_replay.py "<原始 HTML 路径>"
```

## C 检测回归

```powershell
$env:ZIG = "<zig.exe 路径>"
$env:BRICK_REPLAY_REPORT = "<可选的 JSON 输出路径>"
python data/obstacle/check_detector.py
```

| 输入 | 命中 / 17 | 无砖误报 / 15 | 有砖错定位 | 101 帧中时序确认帧数 |
| --- | ---: | ---: | ---: | ---: |
| HTML 冻结 SF2 显示边线 | 13 | 0 | 0 | 15 |
| GitHub SF2 源码重新计算的显示边线 | 13 | 0 | 0 | 14 |
| GitHub main 的 `vision_process` 实测边线 | 8 | 0 | 2 | 6 |

重新计算从附件第 100 张开始，先前的巡线历史不在子集中。C 与 Python 在全部 101 张冻结数据上的首选框逐帧一致。真实确认帧包含未标注帧，不能作为准确率；有效跟踪要求连续三帧且相邻框 IoU ≥ 0.25，丢帧、切换目标、重置和溢出均打断确认。主机单次检测 p95 约 0.046 ms，`main_measured` 含循迹与检测约 0.053 ms。实际板上耗时待测。

固件用行内上四分位参考、30 DN 暗度差、4 行内 23 DN 底边亮度回升，以及底边横向覆盖至少半框宽。ROI 采用同帧下方有效双边行向内收 11 px 的保守投影。稀疏边线只在两个实测行之间插值，跨度至多 12 行、边界位移至多 24 px。记录插值行数，缺测行不向图外外推。面积下限随候选底部行分档。8 邻域以固定 2048 点队列处理，溢出时整帧作废。合成单元测试单独检查 ROI、无效边界、队列溢出、二值 0/1、连续确认与计数回绕。

## RT1064 停车观测

`car_app.c` 在原 `control_frame()` 之后调用检测。摄像头目标可设 `OBSTACLE_SHADOW_ENABLED=1`，默认关闭。启用时只在真摄像头、停车、舵机测试空闲、循迹有效时运行。日志通过现有非阻塞串口队列每秒最多输出一次，图传期间暂停。检测读取已有灰度、二值和双边行，不改变原循迹结果。当前 `main` 的相机工程无环岛状态机，环岛版本的接入须以其完整工程重新验证。

主机适配器测试将真实第 200 张灰度帧重复送入静止相机替身，验证日志、输出约束和限频。时序识别数据使用上节的 101 张独立采集帧。

```text
OBS frame=100 cand=1 confirmed=1 box=87,63,109,69 area=146 contrast=60 binary_dark=691 interp=38 overflow=0
```

已有 `tests/run_tests.py` 在 ASCII 路径副本运行通过，包含 150 项场景合同、2 项表征场景、17 帧时序和 48,986 次检查。应用测试另以 `-DOBSTACLE_SHADOW_ENABLED=1` 编译，并给测试程序传入第 200 张原始灰度帧，观察期间两路电机占空比为零，舵机保持中位。

uVision 5.39 在本机启动时以 `0xC0000005` 退出。使用同一套 Arm Compiler 6.21，读取 `nor_sdram_zf_dtcm` 工程源文件、包含目录、宏和 scatter 配置直接构建。默认版与停车观测版各编译 155 个文件并链接生成 HEX。

```powershell
python data/obstacle/build_armclang.py "$env:TEMP/brick-arm-default"
python data/obstacle/build_armclang.py "$env:TEMP/brick-arm-shadow" --shadow
```
