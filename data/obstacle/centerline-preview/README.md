# 真实灰度与二值图上的中线预览

打开同目录的 [index.html](index.html) 可逐帧或播放第 100–200 张。每幅图从左到右为原灰度与原中线、原 SF2 二值与原中线、新候选线。黄色为原线，青色为候选线，红框为 C 检测框，粉框为人工正面初标。青色虚线表示检测尚未多帧确认。播放固定每张 250 ms，用于观察图像。

新线由现有 C 检测结果驱动的离线像素路径试验生成。使用二值白区、保存的左右边线、障碍物框，向内收缩 8 px 的通道，并把检测框横向扩展 8 px、纵向扩展 4 px。动态规划逐行求线，每行横向移动至多 3 px，相邻移动量变化至多 1 px。缺失边界或无连续通道时拒绝生成。

像素裕量尚未与车宽、距离、转向半径标定。保存边线含补线和历史估计，标注框只覆盖可辨认的砖块正面。此输出不能替代完整砖体、车身扫掠和物理路径验证。当前标定式 C 绕行模块还缺实车标定，本次图像试验没有调用该模块。

17 张初标画面中，正确检出 13 张，正确检出且生成避开标注正面的像素路径 11 张，其中多帧确认 5 张。第 104、108、152、190 张漏检，第 154、162 张在规划范围内有缺失边界。全部 101 张中 34 张生成像素候选线，6 张因缺失边界拒绝，61 张未检出目标。

23 对车端帧号连续且都有候选线的画面中，共同行最大横向变化为 40 px，发生在第 199→200 张。图中绕行侧从右切到左，逐帧优化尚无绕行侧锁定。第 158→159 张也出现 11 px 变化。采集由人工摆砖或推车完成，变化量只描述图像回放。

| 横向试验裕量 | 正确检出且生成路径 / 17 | 共同行最大变化 |
| --- | ---: | ---: |
| 4 px | 11 | 32 px |
| 8 px | 11 | 40 px |
| 12 px | 11 | 48 px |

因此，本次能看到局部绕砖效果，整段连续绕行验证仍未通过。后续需要补强漏检、提供可信边界、锁定绕行侧，并结合标定距离与里程状态机验证。

完整路径、每帧状态和横向变化见 [centerlines.json](centerlines.json)，[comparison.png](comparison.png) 含代表帧，[side-switch.gif](side-switch.gif) 展示第 199→200 张切边。

复现时先运行 `check_detector.py` 生成最新 C 回放报告，再运行 `preview_centerline.py --report <回放报告路径>`。额外的合成检查已验证中央障碍物避让、通道阻断拒绝和缺失边界拒绝，图中素材均来自真实图像。
